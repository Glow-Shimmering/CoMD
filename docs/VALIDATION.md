## 验证边界

- Windows 包在 macOS 上交叉构建，尚未在 Windows 真机启动或验证安装/卸载。
- 新版本与安装包匹配使用模拟 GitHub Release 验证；发布截图中的 0.4.0 是测试数据，并非实际已发布版本。真实接口当前返回状态记录在 validation-report.json；没有为了测试而发布虚假 Release。
- macOS 仅在当前 Apple Silicon 机器实测；最低系统要求 13.0 来自 Electron 运行时元数据，不等于已在 macOS 13 真机测试。
- AI 流程通过本机模拟 Chat Completions 服务验证，没有调用真实付费模型；不同服务商兼容性、密钥存储的跨系统表现仍需真实配置后验收。
- PDF 版面验证覆盖本次测试文档，不代表所有超长表格、大图或极端文档都已验证。
- 未配置 Developer ID / Apple 公证或 Windows 商业代码签名，安装时可能触发系统身份提示。
- 文件保存带外部内容校验与上一版备份，但没有跨进程文件锁，不适合多个程序连续同时写入同一文件。

## 首版范围

本地单用户 Markdown 编辑器，无遥测、无云同步；支持自动检查正式版本，下载安装需手动完成。文件树展示 Markdown/txt 文件，按需展开目录；忽略 .git、node_modules 与符号链接，不提供文件重命名/删除。内嵌 HTML 支持安全标签与常见行内样式，不支持 JavaScript 或全局/外部样式表。实时模式提供语法视觉化编辑；复杂表格、图片和数学内容在双栏/阅读模式完整渲染。未实现 Mermaid 图渲染与多人协作。
